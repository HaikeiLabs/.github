# Haikei Labs

Haikei is the sovereign context framework: build and run agents while you keep your own models and your own data.

Kei puts policies on the tool calls of the agents you run. Agentware is the SDK for the agents you build.

Docs cover both paths, step by step: https://docs.haikeilabs.com

## Two ways to start

- **Build your own agent.** Agentware is the open-source SDK, in Go, Python, TypeScript and Rust. Start with the tutorial: https://docs.haikeilabs.com/tutorials/hacker-news-research-agent. Code: https://github.com/HaikeiLabs/agentware
- **Bring the coding agent you use.** Claude Code, Codex, Cursor, OpenCode or Pi. Put Kei policies on its tool calls: https://docs.haikeilabs.com/kei/get-started/bring-your-agent
